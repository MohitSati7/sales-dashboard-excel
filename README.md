# 📊 Sales Dashboard – Excel Data Analytics Project

An interactive Sales Dashboard built using Excel-compatible spreadsheet tools to analyze sales performance, profitability, customer behavior, and regional sales trends.

This project transforms raw sales data into meaningful visual insights through interactive charts, category filters, and year-wise slicers.

## 📌 Project Overview

The Sales Dashboard provides a comprehensive overview of business performance across different product categories, states, customers, and months.

The dashboard helps users explore sales trends, identify profitable categories, and understand customer contributions through interactive visualizations.

## 🎯 Project Objectives

- Analyze sales performance across different product categories.
- Track profit trends over multiple years.
- Compare sales performance across different states.
- Understand customer distribution and count.
- Identify the top 5 customers contributing to profit.
- Analyze monthly sales trends.
- Provide interactive filtering for better data exploration.

## 📈 Key Dashboard Features

| Feature | Description |
|---|---|
| Sales by Category | Compares sales across product categories |
| Profit Over Time | Tracks profit trends for different years |
| Sales by State | Visualizes state-wise sales performance |
| Customer Count | Displays customer count by year |
| Top 5 Customers | Highlights the top 5 customers by profit |
| Monthly Sales | Shows monthly sales performance |
| Interactive Slicers | Filters dashboard by category and year |
